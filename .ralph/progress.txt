## Codebase Patterns
- Next.js 15 App Router with mixed JS/JSX and TS/TSX
- Tailwind CSS v4 with CSS-first config (no tailwind.config.js, uses @theme inline in globals.css)
- shadcn/ui (New York style) — only 4 components installed (Button, Accordion, AlertDialog, Progress)
- Dark theme by default using CSS custom properties
- Client-side Drizzle ORM usage (db imported in 'use client' components) — unusual but functional via Neon serverless driver
- react-hot-toast for notifications (dark theme, top-right)
- Geist Sans + Geist Mono fonts
- Mixed inline styles (CSS variables) and Tailwind classes in components
- Two DnD libraries coexist: @dnd-kit + @hello-pangea/dnd
- Two icon libraries: lucide-react + react-icons
- Content cached triple-layered: DB + React state + localStorage
- LoadingDialouge (AlertDialog-based) used as a reusable loading overlay
- Components use 'use client' directive even for layouts

## 2026-08-18 - US-001
**Inventory the existing LEAP application**

Files changed:
- `.ralph/docs/application-inventory.md` (created)

**Learnings:**
- LEAP is a Next.js 15 App Router application with Drizzle ORM + Neon PostgreSQL, Clerk auth, Groq AI, YouTube API, and Nodemailer
- The AI service file is named `gemini.ts` but actually calls the Groq API with model `openai/gpt-oss-20b`
- KaTeX and markdown rendering libraries are installed but completely unused — the custom LaTeXRenderer only handles document structure (sections, lists, code blocks) but NOT math expressions
- 7 API routes exist; only 2 have Clerk auth checks (/api/progress and /api/genCertificate)
- /api/deleteCourse and /api/sendCertificate have NO auth — security concern
- Database credentials are hardcoded in drizzle.config.js (committed to repo)
- Drizzle ORM is used directly from 'use client' components — exposes DB connection in browser
- 10+ npm packages are installed but never imported (@google/genai, resend, react-katex, rehype-katex, remark-math, react-markdown, etc.)
- /api/genCourseDetails exists with retry logic but is orphaned — no client calls it
- The `duration` field in CourseDetails is always saved as empty string
- No formal database migrations — uses drizzle-kit push directly
- No .env.example file exists
- Landing page has 3 empty placeholder components (Footer, Features, Pricing)
- Two DnD libraries and two icon libraries coexist in the project
- Content generation is lazy — generated on-demand when user opens a lesson for the first time
- Progress tracking is manual (checkbox) — no video playback time tracking
- The /profile route is protected in middleware but no page exists for it
